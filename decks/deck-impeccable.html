02 · Philosophy

Design that doesn't look like AI made it.

Impeccable is built around a single test: if someone could look at the interface and say "AI made that" without doubt, it has failed. Every rule, every ban, every command exists to push past the training-data reflex into a deliberate, defensible choice.

03 · Setup

Five steps before a single pixel.

Every invocation runs Setup first. Skipping any step produces generic output — and impeccable is explicit that "non-optional" means non-optional.

1

Load context

Run node .claude/skills/impeccable/scripts/context.mjs. Either prints PRODUCT.md / DESIGN.md as a markdown block, or returns NO_PRODUCT_MD — in which case init runs first.

2

Load the sub-command reference

If the user invoked craft / polish / shape / etc., read reference/<command>.md. The reference owns the flow.

3

Read the existing design system

At least one CSS, theme, token, or representative component. Don't reinvent. Branch out only when UX wins.

4

Pick the register

Marketing / landing / portfolio → reference/brand.md. Dashboard / admin / tool → reference/product.md. Resolve by task cue → surface in focus → PRODUCT.md.

5

Seed the palette if new

Brand-new project with no committed colors? Run palette.mjs for a seed brand color and compose the rest in OKLCH.

04 · Register

Brand or product. Pick one, and the rules change.

Impeccable splits all design work into two registers because the success criteria differ. A landing page is allowed to be loud, a dashboard isn't. A product is allowed to be utility-shaped, a brand isn't.

Brand register — design is the product

  • Landing pages, portfolios, campaign sites, long-form editorial
  • One committed brand color carrying 30–60% of the surface
  • Voice and identity over neutral utility
  • Hero asset is real — never a gradient blob with text
  • Reflex-reject aesthetic lanes enforced (no SaaS-cream, no navy-and-gold by default)

Product register — design serves the product

  • Dashboards, admin tools, app shells, data views
  • Restrained: tinted neutrals + one accent ≤10% surface
  • Information density is the success metric
  • States are first-class — loading, empty, error all designed
  • Semantic z-index scale; never arbitrary 9999
05 · Typography

Hierarchy is scale + weight, on a contrast pair.

Two families, paired on a contrast axis: serif display + geometric sans. Max display ≤6rem. text-wrap: balance on h1–h3, pretty on prose. No all-caps body.

06 · Color · OKLCH

08 · Absolute bans

Match and rewrite. No exceptions.

These are not preferences. They are tells. If you find yourself about to write one, rewrite the element with a different structure.

BannedSide-stripe borders

Coloured border-left on cards, list items, callouts. Rewrite with full borders, tints, or leading numbers.

BannedGradient text

background-clip: text + gradient. Decorative, never meaningful. Solid color. Emphasis via weight or size.

BannedDefault glassmorphism

Blurs and glass cards used decoratively. Rare and purposeful, or nothing.

BannedThe hero-metric template

Big number, small label, supporting stats, gradient accent. SaaS cliché.

BannedIdentical card grids

Same-sized cards with icon + heading + text, repeated endlessly.

BannedEyebrow on every section

The tiny uppercase tracked kicker is AI grammar when it's everywhere. One named kicker is voice.

BannedNumbered scaffolding

01 / 02 / 03 above every section. Numbers earn their place only when the section IS a sequence.

BannedOverflowing headings

Long words + large clamp + narrow grids = headline overflow on tablet. Test every breakpoint.

09 · The AI slop test

Two altitudes. The second catches what the first misses.

If someone could look at this interface and say "AI made that" without doubt, it has failed. Cross-register failures are the absolute bans. Register-specific failures live in each reference file.

First-order

Could they guess theme + palette from the category alone?

Fintech that's navy-and-gold. AI tools that are SaaS-cream. Wellness that's beige-pale. If the category gives the answer, it's the first training-data reflex. Rework the scene sentence and color strategy.

Second-order

Could they guess from category-plus-anti-references?

"AI tool that's not SaaS-cream → editorial-typographic." "Fintech that's not navy → terminal-dark." The trap one tier deeper. The first reflex was avoided; the second wasn't. Rework until neither is obvious.
